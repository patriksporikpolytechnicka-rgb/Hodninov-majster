# Angular frontend

Spustenie celej aplikácie: ../docs/DEMO.md.

Vývoj: npm ci, npm start. Backend musí bežať na porte 8080.
Build: npm run build; výsledok je v dist/hodinovy-majster/browser.

Standalone komponenty sú v src/app/pages, API klient a správa tokenu v src/app/core.
Frontend používa iba reálne REST API. Demo dáta poskytuje backend.
